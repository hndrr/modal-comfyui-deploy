# Split app をチャットから使う（MCP 利用ガイド）

このページは、**CPU/GPU 分離構成の Split app（`splitapp.py`）を、ChatGPT Web・Claude Code・Codex から使う人向け**です。保存済みのワークフローを選び、画像・音源・動画を渡して生成し、結果を受け取るまでを説明します。

## 利用前に確認すること

管理者から、MCP の接続先とログイン方法を確認してください。このリポジトリの MCP は Split app 専用です。通常構成の `comfyapp.py` は対象に含みません。

以下の `<SPLIT_PUBLIC_HOST>` は、案内された Split app の公開ホスト名に置き換えます。ホスト名には `https://` や `/mcp` を含めません。接続先は `https://<SPLIT_PUBLIC_HOST>/mcp` です。

接続先をこれから用意する管理者は、[MCP の設定・運用](setup.md)を参照してください。

## 接続する

**ChatGPT Web**：設定からカスタム MCP 接続を追加し、URL に `https://<SPLIT_PUBLIC_HOST>/mcp`、認証方式に OAuth を指定します。ブラウザで Access にログインし、チャットでこの接続を選んでください。生成や添付には書き込み操作を使えるワークスペース権限が必要です。[ChatGPT の接続条件](https://help.openai.com/en/articles/12584461-connecting-custom-mcp-servers-in-chatgpt)

**Claude Code**：使いたいプロジェクトのディレクトリで登録します。

```bash
claude mcp add --transport http --scope local comfyui-remote "https://<SPLIT_PUBLIC_HOST>/mcp"
claude mcp login comfyui-remote
```

**Codex**：次のコマンドで登録してログインし、新しいセッションを開きます。

```bash
codex mcp add comfyui-remote --url "https://<SPLIT_PUBLIC_HOST>/mcp"
codex mcp login comfyui-remote
```

接続したら、まず「保存済みのワークフローを一覧にして。まだ生成しないで」と頼んでみてください。手元で別の MCP サーバーを起動する必要はありません。

## 添付を使って1件生成する

画像を入力にするワークフローがある場合の例です。`動画/短いクリップ.json` は、一覧に出た名前に置き換えてください。

1. **ワークフローを選ぶ**：「保存済みの `動画/短いクリップ.json` を開いて、どの入力ノードに画像を渡すか教えて」
2. **素材を渡す**：ChatGPT なら画像をチャットに添付して「この画像を入力素材として保存して、ワークフローに設定して」と頼みます。音源や動画も同じように渡せます。Claude Code・Codex で手元のファイルを送る方法は[後述](#手元のファイルを送る)します。
3. **生成する**：「そのワークフローを1回だけ実行して、ジョブ ID を返して」。受け付けられると `prompt_id` というジョブ ID が返ります。チャットを閉じてもジョブは続くので、この ID を控えてください。
4. **結果を受け取る**：「そのジョブの進捗を教えて。終わったら動画を返して」。画像や音声も、同じように依頼できます。

生成の受付で通信が切れたときは、「同じ `request_id` と同じワークフローで再試行して」と伝えてください。`request_id` は二重投入を防ぐためのキーです。結果の確認には、受け付けたジョブの `prompt_id` を使います。

## 外部サービスを使うときの承認

生成には Modal の通常の実行料金がかかります。さらに Comfy Cloud や外部 API にプロンプト・歌詞・素材を送るワークフローでは、本人が送信内容と課金先を確認して承認します。同じ「MiniMax Music 3」で曲を作る場合でも、Split app 内でモデルを動かす方法と、Comfy Cloud に送信する方法があります。

1. チャットに確認用リンクが返ります。この時点ではジョブは実行されません。リンクの有効期限は15分です。
2. 自分のブラウザでリンクを開いてログインします。ノードごとに、送信先、課金先、プロンプト・歌詞・モデルなどの入力を確認してください。画像・音声・動画を渡す場合は、送信に使う元の素材もその場で確認できます。最終料金は事前には確定しません。
3. **「この1件を承認して実行」**を押すと、その内容で1件だけキューに入り、ページにジョブ ID が出ます。「送信しない」を押すか期限が切れれば実行しません。

Comfy の Partner Node 経由で Gemini・OpenAI・OpenRouter を呼ぶ場合、引き落とし先は **Comfy のクレジット**です。対応する直接接続ノードで Gemini や OpenRouter を使う場合は、それぞれの API アカウントに課金されます。MCP の OAuth ログインでは外部送信を承認したことになりません。

送信先や送信内容を判断できない場合は、実行前に理由が返ります。たとえば、先に生成する画像を外部に送る場合は、まず Split app 内の生成を終え、「この出力を次のワークフローの入力素材にして」と依頼してから外部サービスに渡してください。承認は確認したワークフローと素材にだけ有効です。内容を変えた場合は改めて承認します。

## 手元のファイルを送る

Claude Code や Codex では、このリポジトリのルートで次のヘルパーを使います。プロジェクト指定の Node.js で依存パッケージを準備し、送りたいファイルだけを引数に渡してください。

```bash
npm ci --prefix mcp --ignore-scripts
node mcp/upload.mjs "https://<SPLIT_PUBLIC_HOST>/mcp" photo.png sound.wav clip.mp4
```

端末に表示された URL でログインすると、ファイルごとに ComfyUI で使える名前が返ります。その名前をチャットで伝え、「この素材をワークフローの入力にして」と依頼してください。チャットに Base64 を貼る必要はありません。中断した場合は同じファイルでコマンドを再実行してください。途中まで送った素材は入力候補に現れません。

1ファイルの上限は **256 MiB** です。画像は PNG・JPEG・WebP、音源は WAV・FLAC・MP3・M4A・Ogg/Opus、動画は MP4・MOV・WebM・MKV を入力に使えます。

## 生成中・生成後にできること

別のチャットやクライアントからでも、同じジョブ ID を伝えて結果を確認できます。

| 依頼の例 | 確認できること・操作の結果 |
| --- | --- |
| 「このジョブはいまどのノード？ 何ステップ目？」 | 実行中のノードと、そのノードが通知した進捗。全体の完了率ではありません。 |
| 「このジョブに何秒かかった？」 | 生成の実行時間、待機を含む経過時間、準備・保存を含む CPU/GPU 実行ワーカーの処理時間。記録がない値は分かりません。 |
| 「このジョブが失敗した理由を調べて」 | 失敗したノードやエラーの詳細。 |
| 「このジョブだけ止めて、停止したかも確認して」 | 指定した1件の取消。実行中は停止要求の受付後に、停止したかを再確認します。完了済みの出力は残ります。 |
| 「待機中のジョブを一覧にして」 | 生成待ちのジョブ。 |
| 「保存されているモデルを一覧にして」 | 保存ファイルの名前・サイズ・更新日時。 |
| 「ComfyUI のモデル選択欄に出る LoRA を確認して」 | ComfyUI が認識している選択肢。保存一覧とは異なり、実際に生成できるかを試す操作でもありません。 |

画像はチャット内のビューアで受け取れます。サイズにかかわらず、ブラウザでログインして開くリンクも返ります。8 MiB を超える画像やビューアで表示できない場合は、そのリンクから閲覧・保存できます。

### 曲を再生・保存する

「このジョブの曲を再生して」と頼みます。MP3・WAV・FLAC・Ogg・Opus を元の形式のまま取得します。ChatGPT では、曲名が表示されたら「再生」を押します。一時停止と再生位置の変更もできます。4 MiB を超える曲は、先に「音声を読み込む」を押してください。

チャット内再生の上限は元ファイル64 MiB・10分・展開後の音声128 MiBです。圧縮ファイルでも展開量を再生前に確認します。上限を超える曲、展開量を確認できない形式、元ファイルを保存したい場合は、返った再生リンクを使います。ブラウザでのログインが必要になる場合があります。

「アプリを表示できませんでした」と出ても、曲を生成し直す必要はありません。再生リンクも見えないときは、「同じジョブの出力一覧から、曲をブラウザで開けるリンクを出して」と頼んでください。ブラウザが再生に対応しない形式でも保存できます。

複数の出力があれば、「2曲目を再生して」「別の動画を見せて」のように指定できます。

### 動画を再生・保存する

「このジョブの動画を再生して」と頼み、チャット内プレイヤーの再生ボタンを押します。MP4を認証付きHTTPSで直接再生し、動画全体の取得完了を待たずに再生できます。

ブラウザのログイン状態などにより直接再生できない場合は、プレイヤーが最大128 MiBまで分割取得を試します。「動画を再取得」は同じ出力を読み直す操作で、再生成はしません。再生できない場合や元ファイルを保存する場合は「保存ページを開く」を使います。

## 保存したワークフローや出力をもう一度使う

ワークフローは「このワークフローで動画の長さを決めているノードを探して」「構成を図にして」のように調べられます。変更を残す場合は、「変更したワークフローを新しい名前で保存して」と依頼してください。ComfyUI の画面で開くための JSON が必要なら、その用途も伝えてください。

通常は「生成して」と頼めば、CPU対応済みのAPIと軽い読み込み・保存・プレビューだけの場合はCPUへ送ります。ローカル生成やCPU対応未登録のノードが含まれる場合はGPUを使います。現時点のAPIノードは実呼び出し未確認のためCPU対応未登録です。「料金優先で」は `gpu: "auto"`、「速度優先で」「Kleinを最速で」は `gpu: "auto-speed"` を指定します。速度優先のローカル推論はRTX PRO 6000を使います。API・軽い入出力だけで承認待ちがない場合は、CPU対応済みでも起動中GPUを再利用します。起動中GPUがなければCPU対応済みはCPU、CPU未登録の既知API・軽い入出力はL4です。外部APIの承認待ちがある場合はGPUの稼働状態を使わず、CPU対応済みならCPU、それ以外の既知API・軽い入出力だけならL4へ固定します。

「今回はL40Sで生成して」のようなGPU指定もできますが、CPU自動実行の対象ならCPUを優先します。「CPUで試して」と明示した場合は `gpu: "CPU"` を指定でき、CPU対応未登録でもCPUで試します。失敗時にGPUで再実行したり、対応済みとして自動登録したりはしません。MCP未対応ノードの拒否と外部APIの承認は維持されます。

受付結果・進捗・承認画面にはCPU/GPUの実行先と理由を表示します。承認待ちや受付結果の再取得では、最初に決めた実行先を維持します。

過去の生成をやり直すには、「このジョブに使ったワークフローを取得して、設定を変えて新しく1回生成して」と頼みます。新しい生成には新しい `request_id` を使います。

元の出力を次の生成に渡す場合は、「このジョブの出力を入力素材にして」と依頼してください。ダウンロードして送り直す必要はありません。入力素材の検索や、画像の寸法・音声や動画の再生時間の確認もできます。

## 利用料金と起動待ち

接続やツール一覧の取得だけでは Modal は起動しません。素材の保存やワークフローの編集・解析には CPU を使います。生成もCPU自動実行の対象または明示CPU試行ならCPU実行ワーカー、それ以外はGPUを使います。保存済みの結果を取得し直す場合は CPU で読み出し、GPU を新たに起動しません。CPU の利用中も料金が発生します。

通常の分離モードでは、ほかに利用がなければ処理後に CPU・GPU が自動停止します。次の操作で起動待ちが発生する場合があります。GPU を常時起動する設定の場合は、生成していない間も稼働します。停止中も保存データのストレージ料金は発生します。

## 困ったとき

- **CPU が起動中**：少し待って同じ操作を再試行してください。「初期化失敗」や実行モードの競合なら、再投入せず管理者に設定を確認してください。
- **ツールが見当たらない**：ChatGPT の接続設定で「ツールを更新」、CLI では新しいセッションで接続し直してください。
- **Web 添付が保存できない**：応答に保存済みのファイル名があるか確認してください。配信元が拒否された場合は管理者に確認してください。署名付き URL をチャットやログに貼る必要はありません。
- **必要なノードやモデルがない**：管理者に追加を依頼してください。追加・更新の手順は[MCP の設定・運用](setup.md#カスタムノードとモデルの管理)にあります。

ツールを直接呼ぶ場合の引数や戻り値は、開発者向けの[ツールリファレンス](tools.md)を参照してください。
